# 夜市摊王

手机竖屏的夜市摆摊对战经营游戏。一条夜市街四个摊位：玩家和三家 AI 摊主，抢中间走过的同一群顾客。

## 玩法

1. **设计摊位**（摊位视角）：点摊位上的招牌、雨棚、摊主、菜单板就能直接改；也可以在下面的标签页里改。
   - 菜品：从 20 种夜市小吃里选（价格参考中国普通城市夜市），自定义菜名、售价、描述。
   - 描述里的关键词会被识别成卖点（现做、大份、祖传、网红、香辣……），不同人群喜欢的卖点不同。
   - 备货：食材当晚用完，剩下的扔掉。
   - 外观与装饰：雨棚、招牌、摊主、吉祥物、灯笼、LED、霓虹灯牌……装饰提升颜值。
   - 商店：技能卡、雇帮手、加菜品位。
   - 对手：三家 AI 的菜单、价格、描述公开可见，每晚会根据生意调整。
2. **出摊**：夜市场景，上下四个摊位，中间是顾客人流。顾客按人群偏好、价格、描述、颜值、口碑、排队长度选择摊位。
3. **技能卡**：吆喝叫卖、限时打折、第二份半价、免费试吃、网红探店、灯光秀、截胡。AI 对手也会出卡。
4. **收摊结算**：利润排名、账本、顾客评价、对手动向。一季 7 晚（周一到周日），总利润第一是“夜市摊王”。

## 文件结构

```
index.html      页面骨架
css/style.css   样式
js/data.js      静态数据：食品与价格、卖点关键词、顾客人群、对手、技能卡、装饰
js/ai.js        AI 接口层：现在是 mock（假数据模拟），预留了 API 调用
js/game.js      游戏主体：摊位设计、夜市运营、结算、存档
```

## 接入 AI API（预留）

`js/ai.js` 里每个决策函数都会先尝试调用接口，失败时退回 mock：

| 函数 | 任务 | 何时调用 |
|---|---|---|
| `AI.prepareNight` | `night_appeal`：AI 扮演各类顾客，给每家每道菜打分 | 每晚开市前一次 |
| `AI.decideBuyer` | 实时用上面的分数 + 价格/排队/技能卡选摊 | 每个顾客（本地计算） |
| `AI.rivalPlan` | `rival_plan`：AI 摊主决定明晚菜单、价格、描述、备货、买卡 | 每晚收摊后 |
| `AI.rivalTactic` | AI 摊主运营中出卡 | 运营中（本地计算） |
| `AI.reviews` | `reviews`：AI 顾客写评价 | 收摊后 |

启用方式：`NM.AI.config = {mode:'api', endpoint:'https://你的后端/nightmarket'}`。
接口收到 `POST {task, payload}`，返回的 JSON 格式写在 `js/ai.js` 顶部注释里。
API Key 放在自己的后端，不要写进前端。

## 运行

纯静态文件，没有依赖。用手机浏览器打开 `index.html`，或开启 GitHub Pages。进度存在浏览器本地。
