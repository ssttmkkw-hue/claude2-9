# 深夜拉面屋

手机竖屏的模拟经营小游戏。城市角落的一间小面馆，晚上六点开门，凌晨两点打烊。

## 怎么玩

1. **点客人**接单，菜会自动下锅（生啤即点即上）。
2. 锅**亮绿光**时点锅出餐，越快越容易拿到"完美"，小费更多。拖太久会变红，然后糊掉。
3. 客人头顶的绿条耗尽就会生气走掉，口碑下降。
4. 打烊后结算：进货、解锁新菜、加灶台和座位、雇伙计、买装饰。

每天会随机遇到不同的情况：下雨、夏日祭、寒潮、菜价上涨、评论家来访、发薪日……
完成一连串目标，最终摘下米其林一星。

## 运行

单个 `index.html`，没有依赖。直接用手机浏览器打开，或开启 GitHub Pages。
进度保存在浏览器本地（localStorage），每天开店前自动存档。
